# HanaV Stock Analyzer v1.0

국내 주식 **한 종목 집중 분석**용 Streamlit 웹앱입니다. KOSPI/KOSDAQ 6자리 코드로 검색할 수 있으며, 시세·기술지표·영업이익 추이·간이 재무건전성·외국인/기관 수급·뉴스·DART 공시를 표시하고 **근거 기반 100점 종합 평가**를 계산합니다.

> **정확성 안내**: 종합 점수는 미래 수익률, 투자 권고, 적정주가가 아닙니다. 일부 항목은 업종 상대평가가 미반영된 v1.0 초기형 휴리스틱입니다. 데이터 공급처 장애·키 부재 시 해당 영역은 **미산출**되며, 가용 항목의 점수만 재가중합니다. 충족률이 낮은 점수는 종목 간 비교하면 안 됩니다.

## 바로 실행하기 (Windows)

1. ZIP 파일을 압축 해제합니다.
2. 폴더 안에서 터미널(PowerShell) 실행:

```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

Python 3.11/3.12 권장. 브라우저에서 보통 `http://localhost:8501`로 열립니다.

## Streamlit Community Cloud 배포

1. 프로젝트 폴더 내용(`app.py`, `data_sources.py`, `scoring.py`, `report.py`, `requirements.txt`, `.streamlit/config.toml` 등)을 **본인 GitHub 저장소** 루트에 업로드합니다. 기존 앱 저장소와 혼동하지 않도록 별도 저장소를 권장합니다.
2. [share.streamlit.io](https://share.streamlit.io/)에서 **Create app** → GitHub 저장소 선택 → Main file: `app.py` → Deploy.
3. Streamlit Cloud **App settings > Secrets**에 필요 시 다음을 등록합니다. 일반 사용자에게 API 키를 요청하는 것보다 운영자가 Secrets에 넣는 편이 안전합니다.

```toml
DART_API_KEY = "본인_OpenDART_인증키"
OPENAI_API_KEY = ""
KIS_APP_KEY = ""
KIS_APP_SECRET = ""
```

해당 정보는 **서버 측에서 사용**됩니다. `secrets.toml` 원본은 GitHub에 절대 올리지 마세요. OpenAI 키는 입력했더라도 **AI 버튼을 누르지 않으면** 호출되지 않습니다. AI 버튼 호출에는 별도 OpenAI API 요금이 발생할 수 있으며 ChatGPT 구독과 별개입니다.

## 처음 사용하는 순서

1. 기본 `005930` 삼성전자를 열어 봅니다. 종목코드 `000660` (SK하이닉스), `035420`(NAVER) 등도 지원합니다.
2. 6자리 코드로는 모든 종목을 직접 조회할 수 있습니다(데이터 제공처가 해당 종목을 제공해야 합니다). **종목명 검색 범위**를 넓히려면 사이드바에서 `KRX 전체 종목 목록 불러오기` 또는 DART 키 설정 후 `DART 상장사 목록 불러오기`를 누르세요.
3. OpenDART 키 없이도 **주가/차트/기술분석/뉴스** 등 공개 접근 가능한 데이터부터 표시합니다. 재무/공시를 사용하려면 [OpenDART 개발자](https://opendart.fss.or.kr/)에서 무료 인증키 발급 후 사이드바에 입력하거나 Secrets에 설정하세요.
4. KIS App Key/Secret이 있다면 **KIS REST 조회 시점 현재가**를 추가로 표시할 수 있습니다. 실시간 WebSocket 스트리밍은 포함하지 않습니다. 실전투자용 키의 접근 권한 및 데이터 재배포 가능 여부는 별도로 확인하세요.
5. 재무 항목과 성장률은 DART 확정 실적 기준이며, **영업이익 시나리오**는 사용자가 가정한 성장률 민감도일 뿐 컨센서스가 아닙니다.
6. `리포트·기록` 탭에서 **인쇄용 HTML**, 평가표 CSV, 점수 스냅샷 JSON을 다운로드할 수 있습니다. HTML을 브라우저에서 열고 인쇄 → PDF 저장이 가능합니다. 이전 JSON을 업로드해 점수 변화도 비교할 수 있습니다.

## 데이터 및 점수 평가 원칙

| 구성 | 연결 방식 | 제한 |
| --- | --- | --- |
| 일봉/종가 | Yahoo Finance → FinanceDataReader 대체 | 공급처 지연/변경에 따라 빈 값 가능; 조정 전 OHLC |
| REST 시세(선택) | KIS OpenAPI `inquire-price` | 본인 App Key·Secret, 조회 시점 스냅샷이며 스트리밍 아님 |
| 확정 재무제표 | OpenDART `fnlttSinglAcnt` | 사용자 인증키 필요; 연결재무제표 우선, 없으면 별도재무제표(혼합 금지) |
| 외국인/기관 수급 | KRX / pykrx | 외부 KRX 엔드포인트 정책 변경 시 일시 중단 가능 |
| 뉴스 | Google News RSS (기사 제목만) | 기사 원문·키워드 문맥 분석 불가, 저신뢰 점수 |
| 공시 | OpenDART `list.json` | 최근 95일, 사용자 인증키 필요 |
| PER/PBR 등 | Yahoo Finance 정보 API | 값의 기준일/정확성이 공시와 다를 수 있음 |
| 생성형 AI 의견 | OpenAI API, 사용자가 버튼 실행할 때만 | 키/별도 요금 필요; 점수 계산에는 관여하지 않음 |

**배점**: 성장성 25 / 가치평가 20 / 수급 15 / 재무건전성 15 / 주가 추세 10 / 뉴스 15 (총 100). 각 영역은 관측 가능한 세부 지표를 0~100 척도로 정규화한 후 점수를 계산합니다. `배점`은 해당 영역의 최대 비중, `영역 점수`는 0~100의 내부 척도입니다. 전체 점수는 **가용 영역 점수 × 배점 / 가용 배점 합계**입니다. 충족률은 실제 가용 영역 **배점의 합계**이며, 같은 영역 안의 세부지표 부족까지 완전히 반영하는 신뢰지표는 아닙니다.

**한계(중요)**

- 수급은 외국인+기관 순매수 금액의 방향과 지속성을 중심으로 평가합니다. 아직 시가총액/거래대금에 대한 완전한 표준화와 공매도·프로그램 매매 해석은 하지 않습니다.
- 가치평가는 동종업종 상대비교와 5년 PER·PBR 밴드를 **아직 제공하지 않습니다**. 현재 점수를 `실질 적정주가`나 확정적 저평가/고평가 판정으로 해석하지 마세요.
- 금융업은 일반 제조업 부채비율 점수에서 제외하지만 은행/보험 고유 건전성 지표를 넣기 전까지 제한이 있습니다.
- 뉴스는 제목의 긍정/부정 키워드만 계산하며, 반어·중복 보도·잘못된 보도를 식별하지 못합니다. 이에 따라 신뢰도가 낮게 표시됩니다.
- 4분기 손익은 **연간 확정값 – 3분기 누적값**으로 생성 가능한 경우만 표시합니다. DART 분기 IS의 `thstrm_amount`는 해당 3개월, `thstrm_add_amount`는 누적입니다. 재무제표 제출·수정 시점이 다를 수 있습니다.
- 당기순이익/부채비율/시총 등의 단순 계산은 특정 업종에서 충분하지 않을 수 있고, 주가 성과에 대한 통계적 검증(백테스트)은 수행하지 않았습니다.
- 외부 고객 공유·유료 서비스에 활용하기 전에 **시세·재무정보·뉴스의 재배포 라이선스와 사내 준법 검토**가 필요합니다.

## 파일 구성

```text
app.py                  Streamlit UI, 차트, 출력, AI 의견 호출

```

## 오류 해결

- **주가가 안 나와요** → Yahoo 또는 FinanceDataReader 외부 데이터 제공처가 막혔을 수 있습니다. 다른 종목을 시도하거나 30분 후 새로고침하세요. 회사 네트워크 정책상 외부 시세 접근이 막힐 수 있습니다.
- **종목명이 안 찾아져요** → 6자리 코드로 검색하거나 `KRX 전체 종목 목록 불러오기`를 누르세요.
- **재무가 없어요** → OpenDART 키를 넣었는지 확인하세요. 보고서 미제출·회사별 계정표 차이·정정 공시의 경우 빈값이 정상일 수 있습니다.
- **수급이 없어요** → KRX 외부 API 접속 제한/스키마 변경 가능성이 있습니다. 다른 영역 분석은 계속 작동합니다.
- **AI 버튼이 안 보여요** → `OPENAI_API_KEY`를 설정하세요. API 키가 없어도 규칙 기반 설명은 작동합니다.
